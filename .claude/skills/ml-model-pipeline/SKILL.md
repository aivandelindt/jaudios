## Rules
- Models are never committed. `make models` reads models/manifest.json, downloads, verifies sha256,
  unpacks. CI caches by sha256.
- Every model has: export script in ml/, ORT-vs-source parity test, and goldens in ml/tests/goldens.json.
- Pin everything: source repo tag/commit, torch version, onnx opset (17), onnxsim version.

## Export scripts
| Model      | Script                       | Source                                   | Parity threshold |
|------------|------------------------------|------------------------------------------|------------------|
| htdemucs   | ml/export_demucs.py          | facebookresearch/demucs v4               | 1e-3 (SDR-neutral) |
| basic_pitch| ml/export_basic_pitch.py     | spotify/basic-pitch                      | 1e-4             |
| openkeyscan3 | ml/export_openkeyscan.py   | rekordcloud/openkeyscan-analyzer @ pinned| 1e-4 on logits   |

### ml/export_openkeyscan.py — requirements
- Clone pinned commit into ml/third_party/openkeyscan-analyzer (git submodule or vendored subdir
  with LICENSE kept). Import model.py from there; do not copy the architecture by hand.
- Load checkpoints/custom/openkeyscan3.pt, eval(), CPU.
- Dummy input (1,1,104,T) with T dynamic; `dynamic_axes={"cqt":{3:"time"}, "logits":{}}`.
- After export: onnxsim; run ORT CPU on 5 fixture CQTs generated by ml/tests/cqt_reference.py
  (which must call the repo's own preprocessing function, not a re-implementation); assert
  max |Δlogits| < 1e-4; write sha256 to stdout for the manifest.

## Goldens (ml/tests/goldens.json)
- Each fixture in tests/fixtures/ has expected values per component. For key: expected Camelot,
  expected class index, and the minimum acceptable margin. Fixtures are our own renders (royalty-free
  or self-produced), never dataset audio.
- `ml/tests/test_goldens.py` runs against the Python reference; `tests/GoldenTests.cpp` runs
  against the C++ engine with the same JSON. Both must pass in CI.

## Dataset tests (ml/tests/test_datasets.py, nightly only)
- GiantSteps Key (eval) → key backends; GiantSteps Tempo → tempo. Datasets are fetched into
  ml/datasets/ by `make datasets` on dev machines/nightly runner only; .gitignored.
